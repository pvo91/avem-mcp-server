# Der Fix für alle Runtime-Vulnerabilities liegt seit Wochen unpushed auf einem lokalen Branch

## What

Der deployte Worker entspricht main mit hono 4.12.19. Auf dem lokalen Branch fix/hono-4.12.28 liegt Commit 4cb9fd7, der hono auf 4.12.28 hebt. Auf diesem Stand meldet npm audit --omit=dev null Vulnerabilities: alle Runtime-Deps (hono, MCP-SDK, zod) sind sauber. Der Branch existiert nicht auf origin, ein Disk-Verlust würde den Fix vernichten, und der Worker läuft weiter auf dem verwundbaren Stand.

## Evidence

git ls-remote zeigt den Branch nicht. npm audit --omit=dev auf dem Branch-Stand: 0. Auf main-Stand: 6 high. wrangler.toml bindet die Custom Domain mcp.avemhq.com im Production-Environment.

## Recommendation

Branch pushen (sofortiges Backup), dann nach main mergen und deploy:production. Danach die Dependabot-PR für hono 4.12.23 schliessen, sie ist überholt.

## Location

`package.json`

## Resolution 2026-07-28

Die Bedingung des Findings ist widerlegt, nicht nur gealtert. Gemessen:

- `git show main:package.json` liefert `"hono": "4.12.28"`.
- Commit `4cb9fd7` ("fix(deps): bump hono to 4.12.28") ist HEAD von `main`.
- `remotes/origin/fix/hono-4.12.28` existiert, der Branch ist also gepusht.

Damit sind beide Kernrisiken weg: der Fix kann nicht mehr durch einen Disk-Verlust
verschwinden, und der verwundbare Stand ist nicht mehr der Stand von `main`.

Offen bleibt EIN Rest, der bewusst nicht als eigenes Finding geführt wird, weil er
eine Handlung ist und kein Befund: der Cloudflare-Worker auf `mcp.avemhq.com` wurde
nach dem Merge nicht nachweislich neu deployt (`npm run deploy:production`). Der
Deploy ist outward-facing und braucht eine ausdrückliche Freigabe, deshalb liegt er
als Task im Radar, nicht hier. Nebenbefund unverändert gültig: die einzige
high-Advisory des alten Stands (GHSA-88fw-hqm2-52qc) greift nur mit
`credentials: true`, und der Server ruft `cors({origin: '*'})` ohne Credentials.

Aufräum-Rest ohne Risiko: `origin/dependabot/npm_and_yarn/hono-4.12.23` ist durch
4.12.28 überholt und kann geschlossen werden.
